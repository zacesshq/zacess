# Zacess app

The Zacess app for every platform, to be built with Tauri and a TypeScript interface over the core.
Work on it has not started yet: this folder is a placeholder. The first usable version of Zacess
runs in a web browser and lives in `apps/web` in the monorepo.

> [!NOTE]
> This is a read-only copy published from [zacesshq/zacess](https://github.com/zacesshq/zacess).
> Issues, discussions and pull requests go there. Changes made here would be overwritten by the
> next publish.

## Building

The app is an npm workspace in the monorepo. There is nothing to build or test yet. Once there is,
the commands will run from a clone of [zacesshq/zacess](https://github.com/zacesshq/zacess) with
`npm ci` at the root.
