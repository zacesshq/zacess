# Accessibility

Zacess exists to make reading accessible, so its own accessibility is held to the highest standard
we can meet.

## Our commitments

- WCAG 2.2 AA as the minimum everywhere. AAA contrast in the reading view.
- Full keyboard use, visible focus and support for switch access and voice control.
- Tested with VoiceOver, TalkBack, NVDA, JAWS and Orca before each release.
- Colour is never the only signal. Motion respects reduced-motion settings.
- Every control is labelled and every image has a description.
- Disabled users test every phase before it ships.

## Status

Zacess is in early development. A conformance report listing supported assistive technologies, known
limitations and test results will be published with the first release.

## Reporting a barrier

An accessibility problem is a bug. Please open an issue describing what you were trying to do, the
assistive technology you use and what went wrong.
